# NEXUS

NEXUS is a personal home automation and AI system designed to connect devices, services, and a local AI agent into one unified system.

## Current Architecture

- **NEXUS** — overall home automation system
- **Nico** — AI/agent persona
- **Nico Terminal** — Vivo Y95 serving as the primary physical interface
- **NEXUS Server** — initially hosted on a Windows laptop during development
- **Mi Home TV** — planned device integration
- **EZVIZ Camera** — planned device integration
